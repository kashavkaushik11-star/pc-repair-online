# PC Repair Online

SEO-friendly static website for online/remote computer support guidance and local repair options.

## Pages
- Home: index.html
- Online Computer Repair: online-computer-repair.html
- Laptop Repair: laptop-repair-service.html
- Windows / PC Troubleshooting: windows-pc-troubleshooting.html

## SEO files
- robots.txt
- sitemap.xml

## Deploy with GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save. Once published, the expected URL is https://kashavkaushik11-star.github.io/pc-repair-online/

## Before launch
Replace/extend contact messaging only after a real service phone, WhatsApp, email or booking backend is configured. The current enquiry form creates a message locally and does not send it to a server. Service coverage and pricing should be confirmed rather than implied as guaranteed.
