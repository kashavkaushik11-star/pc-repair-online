Windows 11 Slow? Safe Ways to Speed Up Your PC

A slow computer can be caused by too many startup apps, low storage, background updates, browser load, overheating or aging hardware. Try these checks one at a time so you can identify what helps.

Before you begin

Save your work and back up important files. Avoid PC cleaner apps that promise instant speed, deleting unknown system files, or changing registry settings based on random advice.

1. Restart and check what is busy

  1. Restart Windows normally, especially if the PC has been running for many days.
  2. Press Ctrl + Shift + Esc to open Task Manager.
  3. Under Processes, check whether CPU, Memory or Disk usage stays unusually high. Sort by a column to identify which app is using resources.
  4. Close only apps you recognise and are not using. Do not end unfamiliar Windows system processes.

2. Reduce unnecessary startup apps

In Task Manager, open Startup apps. Disable only apps you recognise and do not need to launch automatically, such as optional chat or game launchers. Leave security software, drivers and unfamiliar entries enabled until you know what they do.

3. Check free storage space

Open Settings → System → Storage to see what is taking up space. Use Windows Storage settings or Disk Cleanup to remove temporary files you understand. Review the Recycle Bin and Downloads manually before deleting anything.

4. Finish Windows and app updates

Open Settings → Windows Update and check for pending updates. Keep the computer plugged into reliable power during updates. If slowdown began immediately after an update, note the update date and any error message rather than repeatedly forcing shutdowns.

5. Check browser load and unwanted software

  • Close tabs and extensions you do not need.
  • Use Windows Security to run a scan if you suspect unwanted software or pop-ups.
  • Uninstall apps you recognise and no longer use through Settings → Apps → Installed apps.
  • Download drivers and software from the PC maker or official publisher rather than unknown driver-download sites.

6. Check heat and hardware symptoms

If the fan runs loudly, the laptop becomes very hot, or performance drops after a few minutes, make sure vents are not blocked and use the device on a hard, flat surface. Repeated freezes, disk errors, clicking noises or sudden shutdowns may need hardware diagnosis. Back up important files promptly if storage failure is suspected.

7. If it is still slow

Write down the computer model, RAM amount if known, whether it uses an SSD or hard drive, when the slowdown began, and the Task Manager resource that stays high. This evidence is more useful than running multiple optimiser tools.

Quick checklist

  • Restarted the PC
  • Checked Task Manager for high usage
  • Reviewed startup apps
  • Checked storage and Windows Update
  • Scanned with Windows Security if needed
  • Backed up important files

These steps are general guidance; results depend on the cause of the slowdown and the computer's hardware.
